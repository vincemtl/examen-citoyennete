# Examen Citoyenneté

Examen de pratique (hors ligne) pour la citoyenneté canadienne, basé sur le guide *Découvrir le Canada*.
20 questions au hasard, 45 minutes, correction à la fin et historique des résultats enregistré sur l'appareil.

Sur iPhone : ouvrir le site dans Safari → Partager → « Sur l'écran d'accueil ».
